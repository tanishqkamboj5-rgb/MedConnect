# 🩺 MedConnect

### 💙 Your Health, Connected.

MedConnect is a simple and user-friendly healthcare platform built with **React**.  
It helps users explore doctors, book appointments, and access basic nutrition and healthy-lifestyle information — all through a clean and modern interface.

## ✨ Features

| Feature | Description |
|---|---|
| 👨‍⚕️ **Find Doctors** | Explore doctors along with their specializations and ratings |
| 📅 **Book Appointment** | Fill out a simple appointment form |
| 🥗 **Nutrition** | Get basic nutrition and healthy lifestyle tips |
| 🧭 **Easy Navigation** | Move between different sections using React Router |
| 📱 **Clean UI** | Modern healthcare-focused responsive interface |
| ✅ **Booking Confirmation** | Displays confirmation after submitting an appointment |

## 📄 Pages

### 🏠 Home
A welcoming introduction to MedConnect with:

- Hero section
- Why MedConnect
- About MedConnect
- Healthcare highlights

### 👨‍⚕️ Doctors
Displays available doctors with:

- Doctor name
- Specialization
- Rating
- Appointment option

### 🥗 Nutrition
Provides simple and useful information about:

- 🥗 Balanced Diet
- 💧 Staying Hydrated
- 🍎 Healthy Food Choices
- 🥛 Healthy Portions
- 🌱 Daily Healthy Habits

### 📅 Appointment
Users can:

1. Enter their name
2. Select a doctor
3. Choose an appointment date
4. Submit the form
5. Receive a confirmation message ✅
